# Внешний отчёт «Остатки и доступность товаров»

Отчёт для менеджеров: остатки, резервы, ожидаемые поступления и доступность товаров
с разбивкой по датам доступности. Исходная форма — типовой отчёт конфигурации
«1С:Комплексная автоматизация 2» (`Report.ОстаткиИДоступностьТоваров`), вынесенный
во внешний отчёт и доработанный.

## Состав

```
src/ExternalReports/ОстаткиИДоступностьТоваров/
  ОстаткиИДоступностьТоваров.xml      корневой файл (признак отчёта — <ExternalReport>)
  ОстаткиИДоступностьТоваров/         ресурсы: модуль объекта, форма, СКД, справка
    Ext/ObjectModule.bsl
    Forms/ФормаОтчетаСамообслуживание/...
    Templates/ОсновнаяСхемаКомпоновкиДанных/...
```

Это штатная XML-выгрузка Конфигуратора (`/DumpExternalDataProcessorOrReportToFiles`).

## Сборка

```
scripts\build-erf.cmd
```

Собирает все отчёты из `src\ExternalReports\<Имя>\<Имя>.xml` в `build\<Имя>.erf`
(каталог `build` в git не попадает). Нужна платформа 1С 8.3.27 с Конфигуратором;
путь задаётся переменной `V8EXE`. Разборка готового файла обратно в исходники —
`scripts\decompile-erf.cmd "<файл>.erf"`.

## Отличия от типового отчёта

- **Ограничение набора складов.** Список ведёт разработчик в `Ext\ObjectModule.bsl` →
  `ОписанияРазрешенныхСкладов()` (наименования складов; кода у складов нет). На форме склады
  выбираются галочками, отбор ставится в фиксированные настройки компоновщика.
  Пустой список отключает ограничение (режим разработки, выводится предупреждение).
- **Колонки «Дата доступности».** В вариантах СКД группировки
  `КонтрольКачестваДатаДоступности` и `ДатаДоступностиДляСамообслуживания` выключены
  (`use=false`), на форме включаются флажком «Доступность по датам». Из формы их включить
  нельзя: платформа сбрасывает пользовательские настройки группировок к варианту, а правки
  структуры настроек до компоновки не доходят. Поэтому флажок передаётся в
  `ПользовательскиеНастройки.ДополнительныеСвойства["ДоступностьПоДатам"]`, а объектный модуль
  (`ПодготовитьНастройкиКолонок()` в `ПриКомпоновкеРезультата`) включает группировки и убирает
  группу колонок, не соответствующую опции «Контроль качества товаров».
  Если флажок не передан (отчёт открыт без формы) — колонки дат включены.
- **Отбор по номенклатуре «В группе из списка».** В варианте настроек заведён доступный
  пользователю элемент отбора `Номенклатура` с видом сравнения `InListByHierarchy`; он правится
  штатным полем «Отбор» на форме (можно добавить несколько групп). Отбор по `Склад` в варианте
  помечен `Inaccessible` — склады задаются галочками.
- **Пользовательские настройки.** Отбор из поля «Отбор» сохраняется за пользователем в
  `ХранилищеОбщихНастроек` при закрытии формы и восстанавливается при открытии.
- **Правило «>100».** В настройках варианта добавлено условное оформление: значения 100 и больше
  выводятся текстом «>100» (в наличии, доступно, ожидается) — точное количество скрыто.

## Ведение и публикация

Репозиторий содержит только внешние отчёты и скрипты их сборки, конфигурация сюда не попадает.

Исходники ведутся в основном проекте (`CERAMICA_DEMO_25`, каталог `src\erf`), затем
переносятся сюда:

1. скопировать `src\erf\<Имя>.xml` и каталог `src\erf\<Имя>\` в `src\ExternalReports\<Имя>\`
   этого репозитория;
2. закоммитить и запушить:

   ```powershell
   git add -A
   git commit -m "feat(reports): ..."
   git push origin main
   ```

Пушить из основного проекта нельзя: в его истории лежит выгрузка конфигурации (около 2,6 ГиБ),
и она уедет в этот репозиторий.

## Требования к базе

Отчёт использует общие модули конфигурации (`ОбеспечениеВДокументахСервер`,
`КомпоновкаДанныхСервер`, `ОбщегоНазначенияУТКлиентСервер`), поэтому запускается только
на базе соответствующей конфигурации (в разработке — «1С:Комплексная автоматизация 2» 2.5.27).

## Особенности внешних отчётов (проверено на 8.3.27.2074)

- В реквизитах формы нельзя конфигурационные типы (`cfg:CatalogRef.…`): загрузка из XML падает
  с «Исключение XDTO при чтении Form.xml». Поэтому склад в таблице формы — строка (наименование),
  ссылки получаются на сервере.
- `Отчет.Метод()` из формы внешнего отчёта даёт «Метод объекта не обнаружен» (свойства работают).
  Экспортные методы вызываются через `РеквизитФормыВЗначение("Отчет")`.
- Отборы по «Склад» и «Номенклатура.Артикул» ставятся в фиксированные настройки; одноимённые
  элементы из настроек варианта удаляются, иначе «Пересекаются элементы отбора».
- Структурные правки формы надёжнее делать в Конфигураторе: открыть `.erf`, поправить форму,
  сохранить и разобрать обратно `scripts\decompile-erf.cmd`.
